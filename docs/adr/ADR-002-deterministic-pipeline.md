# ADR-002：确定采集 Pipeline，Agent 负责研究闭环

- **状态**：已采纳
- **日期**：2026-09-24

## 背景

如果让 Agent 负责采集、去重、入库和调度，会产生不可复现、难审计和高成本问题；如果 Agent 只做一次文本总结，又无法体现专用 Agent 价值。

## 候选选项

1. 全 Agent Pipeline：灵活，但可靠性、成本和权限风险高。
2. 全确定性脚本：稳定，但缺少研究判断、工具调用和证据补齐。
3. 确定性采集 + Agent 研究：边界清晰，便于测试和评测。

## 决定

采集、清洗、快照、去重、候选排序由 Python、规则和 SQL 完成；Agent 只处理研究计划、工具查询、证据验证和报告写作。

## 理由

将可靠性要求高的步骤保持确定性，把不确定性隔离在受限 Agent Runtime 中，可以同时满足工程性和 Agent 赋能目标。

## 后果

- 正面：数据可回填、可重试、可审计；Agent 成本和风险可控。
- 代价：需要维护 Pipeline 与 Agent 之间稳定的数据契约。
