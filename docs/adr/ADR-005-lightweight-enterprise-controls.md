# ADR-005：实现轻量企业控制并保留扩展接口
> 层级：决策日志｜记录一次决策当时的选项、理由与后果；不是开发进度流水

- **状态**：已采纳
- **日期**：2026-09-24

## 背景

项目需要体现企业对权限、审计、Token 成本和数据保护的考虑，但个人开发者无法在合理时间内完成企业 SSO、ABAC、完整 DLP、KMS 和合规认证。

## 候选选项

1. 忽略企业控制：实现快，但不符合真实企业需求。
2. 完整企业治理：展示完整，但完成成本过高且容易变成无法运行的架构。
3. 轻量控制 + 扩展点：实现关键风险控制，明确未完成边界。

## 决定

首期实现本地认证、`ADMIN/EDITOR/VIEWER` 三角色、报告可见范围、基础审计、脱敏、模型白名单和 Token 预算；SSO、ABAC、多租户、DLP 和 KMS 只预留 Provider 接口。

## 理由

该方案能在个人项目中真实验证权限和成本意识，同时避免用未经验证的关键词夸大企业能力。

## 后果

- 正面：安全性可演示，范围可控，简历描述真实。
- 代价：不能宣称达到企业完整合规或高可用标准，需要明确 Limitations。
