# ADR-001：采用单个专用研究 Agent

- **状态**：已采纳
- **日期**：2026-09-24

## 背景

老项目已经使用 LangGraph 多 Agent 完成学习规划。新项目需要增加 AI Agent 比重，但也要与老项目区分，并控制个人开发复杂度。

## 候选选项

1. 单个通用聊天 Agent：实现简单，但缺少领域调教、工具闭环和可验证性。
2. 多个 Agent 自由协作：展示力强，但状态复杂、评测困难，且与老项目重复。
3. 单个专用研究 Agent：围绕开源情报任务配置工具、状态、预算和评测。

## 决定

采用单个专用研究 Agent，使用 LangGraph 有界状态图，不采用 Multi-Agent。

## 理由

项目的核心价值是提升周报效率，而不是制造多 Agent 复杂度。专用 Agent 更容易控制预算、审计轨迹、验证证据和做消融对比。

## 后果

- 正面：架构更简单，质量归因清晰，Agent 调教有明确指标。
- 代价：不展示 Agent 间协作；该能力由老项目承担。
