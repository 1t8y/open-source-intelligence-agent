采集与运行

这条链路分三层：流水线运行是链上的每一段（采集 → 快照 → 排名 → 正文缓存，以及按主题的 研究 / 发布 / 推送）；Agent 运行是「研究」这一段内部的完整轨迹（规划、工具、成稿、自检）； 回填任务是「采集」之前的历史补齐，按页遍历仓库。三层都只对管理员和编辑者开放。

Agent 运行

每条运行有三种收尾：已完成（证据齐全，产出了报告）、需人工复核（跑完了，但证据不足以支撑成稿）、 失败（模型、传输出错）。「需人工复核」是这条运行的终态 —— 它没有报告，所以没有「通过」这个动作； 能做的是点 # 打开它，看轨迹、确认原因，然后记一条复核结论（「已确认原因」或「要重跑」）。 那张表里「复核」一列显示每条运行的最后结论；筛「还没人看过」就是待处理的那批。

回填任务
